# ARYA SOC Assistant — Project Notes

## Concept

ARYA is an AI SOC assistant designed to help with security monitoring, alert analysis, investigation support and automation.

## Documented components

- 3D/cyber-themed web interface
- Frontend and backend
- Audio/voice component
- AI/chatbot functionality
- Planned skill-router integration
- Kali Linux security lab

## Security tools used in the lab

- Suricata — network IDS
- Wireshark — packet analysis
- Nmap — network/service discovery
- Metasploit — controlled security testing

## Planned direction

A future skill-routing layer can select the appropriate defensive workflow based on the user's request, such as alert triage, log analysis, incident reporting or security-tool assistance.

## Portfolio positioning

ARYA should be presented as an AI-assisted SOC project demonstrating security monitoring, alert triage, automation and integration with a cybersecurity lab.
